# Personal Skills

Open-source Codex skills by Lorenzo Borgato.

## Skills

### [NPM Package Guard](./npm-package-guard)

Audit direct npm dependencies before installation and optionally block risky
package-manager commands with a Codex hook.

```bash
npx --yes @elgabor/npm-package-guard@latest
```

Each skill is self-contained in its own directory. The npm package, public
documentation, tests, and distributable Codex skill live together so releases
can be reproduced from this repository.
